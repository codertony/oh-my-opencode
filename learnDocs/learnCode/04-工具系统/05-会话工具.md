## 核心职责

会话工具模块负责管理和查询 OpenCode 的会话历史数据。它提供四种核心能力：

1. **会话列表查询**（session_list）：列出所有可用的会话，支持按日期范围、项目路径过滤
2. **会话内容读取**（session_read）：读取指定会话的完整消息历史，可选包含待办事项和转录日志
3. **会话内容搜索**（session_search）：在会话消息中进行全文搜索，支持跨会话或单会话搜索
4. **会话元数据获取**（session_info）：获取会话的统计信息，包括消息数量、时间范围、使用的 Agent 等

这些工具使 Agent 能够回顾历史会话，从中提取上下文信息，实现跨会话的知识复用。在复杂的多轮对话场景中，会话工具可以帮助 Agent 理解用户的历史需求和之前的解决方案。

## 4 个会话工具

### 1. session_list

`session_list` 工具用于列出所有可用的 OpenCode 会话。它支持按日期范围和项目路径进行过滤，返回格式化的会话列表表格。

**参数说明：**
- `limit`（可选）：返回的最大会话数量
- `from_date`（可选）：起始日期过滤（ISO 8601 格式）
- `to_date`（可选）：结束日期过滤（ISO 8601 格式）
- `project_path`（可选）：按项目路径过滤

**代码实现**（`src/tools/session-manager/tools.ts` 第 34-61 行）：


**使用场景：**
- 查找最近的工作会话
- 按日期范围检索历史会话
- 获取当前项目的所有会话

### 2. session_read

`session_read` 工具用于读取指定会话的完整消息历史。支持可选加载待办事项列表和转录日志。

**参数说明：**
- `session_id`（必需）：要读取的会话 ID
- `include_todos`（可选）：是否包含待办事项列表（默认 false）
- `include_transcript`（可选）：是否包含转录日志（默认 false）
- `limit`（可选）：返回的最大消息数量

**代码实现**（`src/tools/session-manager/tools.ts` 第 71-93 行）：

```typescript
execute: async (args: SessionReadArgs, _context) => {
  if (!(await sessionExists(args.session_id))) {
    return `Session not found: ${args.session_id}`
  }

  let messages = await readSessionMessages(args.session_id)
  
  if (args.limit && args.limit > 0) {
    messages = messages.slice(0, args.limit)
  }

  const todos = args.include_todos ? await readSessionTodos(args.session_id) : undefined

  return formatSessionMessages(messages, args.include_todos, todos)
}
```

**使用场景：**
- 回顾之前的对话内容
- 分析历史会话中的决策过程
- 提取之前会话中的代码片段或解决方案

### 3. session_search

`session_search` 工具用于在会话消息中进行全文搜索。支持跨所有会话搜索或在特定会话内搜索，支持大小写敏感选项。

**参数说明：**
- `query`（必需）：搜索查询字符串
- `session_id`（可选）：仅在指定会话中搜索（默认搜索所有会话）
- `case_sensitive`（可选）：是否区分大小写（默认 false）
- `limit`（可选）：返回的最大结果数量（默认 20）

**代码实现**（`src/tools/session-manager/tools.ts` 第 104-134 行）：

```typescript
execute: async (args: SessionSearchArgs, _context) => {
  const resultLimit = args.limit && args.limit > 0 ? args.limit : 20

  const searchOperation = async (): Promise<SearchResult[]> => {
    if (args.session_id) {
      return searchInSession(args.session_id, args.query, args.case_sensitive, resultLimit)
    }

    const allSessions = await getAllSessions()
    const sessionsToScan = allSessions.slice(0, MAX_SESSIONS_TO_SCAN)

    const allResults: SearchResult[] = []
    for (const sid of sessionsToScan) {
      if (allResults.length >= resultLimit) break
      const remaining = resultLimit - allResults.length
      const sessionResults = await searchInSession(sid, args.query, args.case_sensitive, remaining)
      allResults.push(...sessionResults)
    }

    return allResults.slice(0, resultLimit)
  }

  const results = await withTimeout(searchOperation(), SEARCH_TIMEOUT_MS, "Search")
  return formatSearchResults(results)
}
```

**使用场景：**
- 查找之前讨论过的特定话题
- 搜索历史会话中的代码示例
- 定位包含特定关键词的会话

### 4. session_info

`session_info` 工具用于获取指定会话的详细元数据和统计信息，包括消息数量、时间范围、使用的 Agent 等。

**参数说明：**
- `session_id`（必需）：要查询的会话 ID

**返回信息：**
- 会话 ID 和消息数量
- 第一条和最后一条消息的时间
- 会话持续时间
- 使用的 Agent 列表
- 是否有待办事项和转录日志

## 会话工具流程

会话工具的使用遵循以下典型流程：

1. **发现阶段**：使用 `session_list` 获取可用会话列表
2. **选择阶段**：根据时间范围或项目路径筛选目标会话
3. **查询阶段**：使用 `session_info` 获取会话元数据，确认是否为目标会话
4. **读取阶段**：使用 `session_read` 读取完整消息内容
5. **搜索阶段**：使用 `session_search` 在会话中查找特定内容

## 关键代码片段

### 片段 1：会话搜索实现

来自 `src/tools/session-manager/session-formatter.ts` 第 149-199 行：

```typescript
export async function searchInSession(
  sessionID: string,
  query: string,
  caseSensitive = false,
  maxResults?: number
): Promise<SearchResult[]> {
  const messages = await readSessionMessages(sessionID)
  const results: SearchResult[] = []

  const searchQuery = caseSensitive ? query : query.toLowerCase()

  for (const msg of messages) {
    if (maxResults && results.length >= maxResults) break

    let matchCount = 0
    const excerpts: string[] = []

    for (const part of msg.parts) {
      if (part.type === "text" && part.text) {
        const text = caseSensitive ? part.text : part.text.toLowerCase()
        const matches = text.split(searchQuery).length - 1
        if (matches > 0) {
          matchCount += matches
          const index = text.indexOf(searchQuery)
          if (index !== -1) {
            const start = Math.max(0, index - 50)
            const end = Math.min(text.length, index + searchQuery.length + 50)
            let excerpt = part.text.substring(start, end)
            if (start > 0) excerpt = "..." + excerpt
            if (end < text.length) excerpt = excerpt + "..."
            excerpts.push(excerpt)
          }
        }
      }
    }

    if (matchCount > 0) {
      results.push({
        session_id: sessionID,
        message_id: msg.id,
        role: msg.role,
        excerpt: excerpts[0] || "",
        match_count: matchCount,
        timestamp: msg.time?.created,
      })
    }
  }

  return results
}
```

### 片段 2：会话信息格式化

```typescript
export function formatSessionInfo(info: SessionInfo): string {
  const lines = [
    `Session ID: ${info.id}`,
    `Messages: ${info.message_count}`,
    `Date Range: ${info.first_message?.toISOString() ?? "N/A"} to ${info.last_message?.toISOString() ?? "N/A"}`,
    `Agents Used: ${info.agents_used.join(", ") || "none"}`,
    `Has Todos: ${info.has_todos ? `Yes (${info.todos?.length ?? 0} items)` : "No"}`,
    `Has Transcript: ${info.has_transcript ? `Yes (${info.transcript_entries} entries)` : "No"}`,
  ]

  if (info.first_message && info.last_message) {
    const duration = info.last_message.getTime() - info.first_message.getTime()
    const days = Math.floor(duration / (1000 * 60 * 60 * 24))
    const hours = Math.floor((duration % (1000 * 60 * 60 * 24)) / (1000 * 60 * 60))
    if (days > 0 || hours > 0) {
      lines.push(`Duration: ${days} days, ${hours} hours`)
    }
  }

  return lines.join("\n")
}
```

### 片段 3：消息读取与格式化

来自 `src/tools/session-manager/session-formatter.ts` 第 44-84 行：

```typescript
export function formatSessionMessages(
  messages: SessionMessage[],
  includeTodos?: boolean,
  todos?: Array<{ id?: string; content: string; status: string }>
): string {
  if (messages.length === 0) {
    return "No messages found in this session."
  }

  const lines: string[] = []

  for (const msg of messages) {
    const timestamp = msg.time?.created ? new Date(msg.time.created).toISOString() : "Unknown time"
    const agent = msg.agent ? ` (${msg.agent})` : ""
    lines.push(`\n[${msg.role}${agent}] ${timestamp}`)

    for (const part of msg.parts) {
      if (part.type === "text" && part.text) {
        lines.push(part.text.trim())
      } else if (part.type === "thinking" && part.thinking) {
        lines.push(`[thinking] ${part.thinking.substring(0, 200)}...`)
      } else if ((part.type === "tool_use" || part.type === "tool") && part.tool) {
        const input = part.input ? JSON.stringify(part.input).substring(0, 100) : ""
        lines.push(`[tool: ${part.tool}] ${input}`)
      } else if (part.type === "tool_result") {
        const output = part.output ? part.output.substring(0, 200) : ""
        lines.push(`[tool result] ${output}...`)
      }
    }
  }

  if (includeTodos && todos && todos.length > 0) {
    lines.push("\n\n=== Todos ===")
    for (const todo of todos) {
      const status = todo.status === "completed" ? "[x]" : todo.status === "in_progress" ? "[-]" : "[ ]"
      lines.push(`${status} [${todo.status}] ${todo.content}`)
    }
  }

  return lines.join("\n")
}
```

## 实战示例

### 示例 1: 查找历史会话

**场景**：用户想要回顾上周关于用户认证功能的讨论。

**执行步骤**：

1. 首先列出最近 10 个会话：
```
session_list(limit=10)
```

2. 根据返回的会话列表，找到感兴趣的会话 ID（例如 `ses_auth_20241215`），获取其详细信息：
```
session_info(session_id="ses_auth_20241215")
```

3. 确认是会话后，读取完整内容：

```
session_read(session_id="ses_auth_20241215", include_todos=true)
```
